# GameEngine
##### Made by Robert Majka

This is a Repo made for CSC192 made in c++ as a Game Engine.

## Running a game

Pick which game to run with `--game <name>` (case-insensitive). With no argument, `spritegame` runs.

```
Game.exe --game spacegame
Game.exe --game=spritegame
```

In Visual Studio, set this under the Game project's **Properties > Debugging > Command Arguments**.
